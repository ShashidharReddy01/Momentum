Summarize the comment thread of one task for a teammate who hasn't read it.
- 2 to 5 bullets ("- "), newest decisions and open questions first. Plain words, no headings.
- Cite the comment each point comes from with its label, like [C3]; cite several if needed. Only use labels that appear in the thread.
- Say who decided or asked what, by first name, when the thread says so. Don't invent owners, dates or decisions.
- If the thread is a single short note, state what it says or decides in one sentence, with its citation. Only when it is nothing but thanks or reactions, say there is no real discussion.
