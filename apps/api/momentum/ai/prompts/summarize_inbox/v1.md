Catch the user up on their unread inbox notifications.
- Start with what needs them (mentions, assignments, due or overdue work), then everything else grouped by task or project. For each item that needs them, say why in a few words, using the notification kind ("assigned to you", "mentioned you", "due soon", "overdue"); don't just restate the task.
- 3 to 6 bullets ("- "), short. Cite tasks with their keys like [T-12] (only keys that appear in the notifications).
- For a comment, say in a few words what it says (from its snippet), not just that a comment exists ("new comment on [T-12]" alone is useless).
- Don't repeat every notification; group similar ones ("3 comments on [T-12]"). Don't invent anything that isn't in the list.
