Catch the user up on their unread inbox notifications.
- Start with what needs them (mentions, assignments, due or overdue work), then everything else grouped by task or project.
- 3 to 6 bullets ("- "), short. Cite tasks with their keys like [T-12] (only keys that appear in the notifications).
- Don't repeat every notification; group similar ones ("3 comments on [T-12]"). Don't invent anything that isn't in the list.
