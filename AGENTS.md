# AGENTS.md

All AI coding agents (Claude Code, Copilot, Cursor, Codex, etc.) follow **`CLAUDE.md`**. It's the single operating manual for this repository.

Quick pointers:
- Current state and next slice: `docs/progress/STATUS.md`
- What to build: `docs/roadmap/phase-N.md`
- How to build it: `docs/process/ai-dev-workflow.md`, `docs/engineering/coding-standards.md`
- Gate: `make check` must be green before you report a slice as done.
